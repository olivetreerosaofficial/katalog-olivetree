# Katalog Olive Tree (statis)

Satu halaman HTML tanpa server, tanpa login, tanpa database. Gratis di GitHub Pages.

## Lihat di komputer
Klik dua kali `index.html`.

## Edit produk
Buka `data/products.js`, ubah/tambah blok produk (jangan lupa koma antar produk).
Foto taruh di folder `images/produk/`, lalu tulis path-nya di `foto`.
Tips: lebar foto ~1000px, ukuran <300KB supaya cepat dibuka.

## Publish (di akun GitHub-mu sendiri)
1. Buat repo baru di akunmu, mis. `katalog`.
2. Add file -> Upload files: upload semua isi folder ini (termasuk `.nojekyll`), Commit.
3. Settings -> Pages -> Deploy from a branch -> `main` / `(root)` -> Save.
4. Tunggu 1-2 menit. Alamat: `https://USERNAME.github.io/katalog/`

Catatan: akun GitHub gratis biasanya butuh repo **public** untuk Pages.

## Update
Di GitHub, buka file -> ikon pensil -> edit -> Commit. Situs otomatis ter-update.
Stok diubah manual di `jumlah`.
